# Parcours francais : base-account-privy (integration Base Account dans Privy)

Lecture pedagogique du depot base/base-account-privy : un starter Next.js montrant comment integrer Base Account comme option de portefeuille au sein de la plateforme d authentification Privy.

Sommaire :

Chapitre 1 Presentation de base-account-privy. Chapitre 2 Configurer Privy pour Base Account et authentifier avec SIWE. Chapitre 3 Retrouver et creer des Sub Accounts a travers l abstraction Privy. Chapitre 4 Permissions de depense avec la librairie navigateur de Base Account. Chapitre 5 Au-dela de Base Account, ce que Privy ajoute et limites du parcours.

Ce parcours est une lecture pedagogique du code source et de la documentation du depot, sans installation ni execution du projet.
